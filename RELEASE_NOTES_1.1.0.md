New charcoal-and-indigo desktop interface, scrollable configuration panels,
always-visible activity output, and clearly separated build/install/recovery
actions. NuttyMod Root inputs remain available without hiding action buttons.

Matching professional GitHub Pages site with download links, flashing steps,
Root Mode information and recovery guidance.

All existing CPE, Root Mode, userdata, backup, undo and restore features remain.
Root Mode packages are the matching v1.0.0 set with library v1.2. Integrated
game rebuild source stays pinned to the checksum-verified v1.0.0 source release.

Close the game before install/restore. Unlock CPELoader first and only flash
trusted code. Incorrect flashing can corrupt the game. Game-level Root Mode
does not provide Windows administrator access or disable integrity warnings.
