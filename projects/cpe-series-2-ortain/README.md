# CPE Series 2 — Ortain 2.0.0

CPE/1-compatible extension of CPE Rephysics, not a new solver. Includes bounded neon motion trails, a radial pulse API and the Ortain loading preset supported by CPE Flasher Tool 1.2.1.

Select this folder with the flasher's CPE project selector, or use its bundled-project button on Custom Cube. Original portable game, unlocked loader, userdata and compilation dependencies are still required. See `CUSTOM_CUBE.md` in the flasher repository for packaging and recovery instructions.
