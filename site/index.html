BEFORE YOU FLASH

Back up. Unlock. Close.

Incorrect flashing can corrupt the game. Only compile trusted code, unlock CPELoader with Ctrl+A → Y, and close the game before install or restore.

Use Python 3.11+ with pygame, pymunk, and PyInstaller. Obtain the original game ZIP and its checksum file from the official game releases.

The flasher download is not the game portable ZIP.

GOOD TO KNOW

Before your first flash.

Does Root Mode give Windows administrator access?

No. Root Mode is a game-level library for NuttyMod Root. It does not grant OS root access and cannot disable required CPELoader integrity warnings.

What does Undo changes restore?

It restores the last flash completed in the current app session. Before installation, it only discards the prepared build. Restore backup lets you select an earlier backup. Recorded files are restored, files added by that flash are removed, and unrelated saves are preserved. A recovery snapshot is created first.

Where does my userdata go?

It stays in the selected game folder. The flasher does not upload userdata or local VP logs. A flashed portable ZIP contains userdata, so remove private information before sharing it.

Can I build the app myself?

Yes. The MIT-licensed repository includes the app source, build scripts and Windows workflow. Integrated game rebuild source is available in the release, with third-party licensing notices included.
