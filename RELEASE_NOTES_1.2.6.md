# CPE Flasher Tool 1.2.6

**05 Custom Cube** now has six TAR slots. Browse or type paths, clear a slot without deleting its TAR, and select exactly one overlay before building. The confirmation names the selected package. Changing a slot or the active selection clears a previously prepared flash.

Slots are saved in the flasher's local Windows preferences on close. The next launch starts on **No overlay**, so a saved path is never run automatically. The bundled Ortain button still works and can be saved in a slot. Game-version support, manifest verification, loader checks and backup/restore behavior are unchanged.
