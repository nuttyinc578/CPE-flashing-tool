# CPE Flasher Tool 1.2.7

The **01 Game** tab lists the free Windows builds with bundled rebuild source:

- Stable: **6.4.1** and **6.4.2**.
- Nightly: **6.4.2-nightly**, **6.4.3-nightly**, **6.4.3-nightly.2**, and **6.4.3-nightly.3**.

Choose the original portable ZIP and an unlocked installation of the same version. The default source selection uses the portable's embedded source or the matching bundled profile. Rebuilds preserve Nightly 3's DVD archive art, original EXE version, and CPE repair files. The 6.4.2 and Christmas builds use the game's Python 3.15.2 environment with pygame-ce, Pymunk, and PyInstaller. The flasher does not match setup EXEs or PLUS builds, or substitute stable, nightly, or older source for another version.

Stable 6.4.3 is not bundled. The December 2 countdown remains informational; support for a future stable release requires that release's original portable and exact matching source.
