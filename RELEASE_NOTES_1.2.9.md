# CPE Flasher Tool 1.2.9

Use **05 Custom Cube → Use bundled Build Mode TAR**, then **Flash ZIP + Recompile**. The mod adds a Build Mode button and **B** shortcut in the flashed game's solo sandbox. Place blocks, balls and fixed beams on the grid, rotate beams and undo placement. The mod leaves multiplayer unchanged.

The bundle button checks an existing Build Mode slot or fills the first empty one. Other checked packages stay selected. Existing loader unlock, Full rewrite, verification and backup requirements still apply.
