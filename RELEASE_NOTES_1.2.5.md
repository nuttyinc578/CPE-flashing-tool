# CPE Flasher Tool 1.2.5

The game tab identifies the supported **free** Windows editions. Choose the original portable ZIP and an unlocked installation of the same version. Leave the rebuild source at its default to use the matching bundled profile for 6.4.1, 6.4.2 or 6.4.3-nightly.2. A supplied source tree must match the game's embedded version. Do not select the repair utility `cpe.exe`, a setup EXE or the private PLUS installation.

6.4.3 stable is planned for December 2, 2026. Its profile requires the matching stable ZIP, installed game and trusted stable rebuild source when available; no stable download is bundled or implied. Countdown target: 00:00 Toronto time (05:00 UTC). After that time the UI directs you to check releases; no automatic downloads or installation occur.

For 6.4.2 and the Christmas nightly, select the game's Python 3.15.2 environment with pygame-ce 2.5.8, pymunk 7.3.1 and PyInstaller 6.22.3. Source selection uses the release's own build spec. Loader unlock checks, checksums, backup/restore and explicit confirmation before replacing installed files remain in effect.
