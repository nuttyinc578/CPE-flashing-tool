# CPE Flasher Tool 1.2.8

Check one or more of the six **05 Custom Cube** slots to apply trusted TAR packages together. The build confirmation lists the selected slots in order, and the game runs their startup hooks in that order. If two selected packages target the same file, the flasher names both packages and stops before compiling.

**Uncheck all** leaves package paths in place. The next launch starts with every slot unchecked. Existing Full rewrite, loader unlock, backup, and game version requirements are unchanged.
