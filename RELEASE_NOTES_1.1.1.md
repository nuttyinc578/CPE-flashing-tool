# CPE Flasher Tool v1.1.1 — Security / OG menu

Adds **Security ??? / OG Menu** to NuttyMod Root Settings. The button opens
the existing security door, Broken Lands terminal, login and OG-version menu,
then returns to Root Settings. Opening it does not unlock CPELoader or start
a download/restore automatically. Original recovery confirmations remain.

The settings layout now keeps all controls and Save/Back visible. The flasher
bundles updated Root support on top of the verified base game source. Reflash
and recompile your game with this release to make the button appear.

Existing Root Mode v1.2 packages remain compatible. No erase or permanent-install
behavior was added. Keep backups, close the game before replacing/restoring it,
and only compile trusted code.
